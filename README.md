Расширение конфигурации [1С:Конвертация данных 3.1](https://its.1c.ru/db/metod8dev#content:5846:hdoc), адаптирующее типовой механизм обмена под работу с произвольным XDTO в [1С: Адаптер Kafka](https://github.com/ShadobaAI/kafka-adapter).

## Назначение

При использовании обработчика типа **«КД 3.1»** адаптер передаёт данные через модуль обмена, сгенерированный в 1С:Конвертации данных. Стандартный механизм КД 3.1 ориентирован на формат **EnterpriseData**. Данное расширение позволяет использовать вместо него **произвольный XDTO-пакет** — то есть контракт данных, специфичный для вашей интеграции.

## Базовая конфигурация и границы

Расширение разрабатывается и проверяется совместно с локальной базовой конфигурацией `conversion/КД` (`КД` / `КонвертацияДанных`). База не входит в этот Git-репозиторий. Расширение заимствует отдельные объекты КД, включая `Справочник.ПравилаКонвертацииОбъектов`, и дополняет их собственными объектами с префиксом `кфк`.

Проверка текущего checkout подтверждает attachment только к одной локальной версии базы. Заявленная линия совместимости — **КД 3.1+**, однако совместимость с каждым обновлением этой линии не гарантируется автоматически. При обновлении КД необходимо проверить заимствованные объекты, пути данных форм и end-to-end генерацию контракта через `conv-edt`.

Расширение отвечает за описание и генерацию контрактов/модулей обмена, но не реализует Kafka transport. Низкоуровневый обмен остаётся ответственностью Kafka Adapter и внешней компоненты.
